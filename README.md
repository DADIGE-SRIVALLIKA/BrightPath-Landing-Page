# BrightPath — Responsive Landing Page

A clean, responsive landing page built for the Web Development Internship Task 1.

## Files
- `index.html` — semantic HTML5 page structure and content.
- `style.css` — layout, colors, typography, responsive navigation, and media queries.

## Features
- Header with brand and navigation links
- Hero section with headline, supporting text, and call-to-action
- Feature cards and a three-step section
- About section and footer with social links
- Responsive layout for desktop, tablet, and mobile screens
- CSS Grid, Flexbox, hover states, and reduced-motion support
- Accessible navigation label, descriptive links, and image-free CSS illustration

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or install the free **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Resize the browser or use Developer Tools → device toolbar to test mobile layouts.

## Customize
- Change the brand name and page copy in `index.html`.
- Change colors and spacing in the `:root` variables at the top of `style.css`.
- Replace the example social links and email address with your own links before publishing.

## Technologies
HTML5 and CSS3 (Flexbox, Grid, media queries). No paid tools or JavaScript dependencies are required.
